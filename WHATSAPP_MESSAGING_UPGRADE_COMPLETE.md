## 🎨 VISUAL HIERARCHY RULES

### Emoji Usage Guide
| Emoji | Meaning | Usage |
|-------|---------|-------|
| 🔐 | Security, PIN codes | Payment secured, PIN delivery |
| ✅ | Success, confirmation | Transaction complete, action confirmed |
| ❌ | Failure, cancellation | Payment failed, transaction cancelled |
| ⏰ | Time-related, deadlines | Expiry, delays |
| 💰 | Money, refunds | Refund completed |
| ⚠️ | Warning, attention needed | Important instructions |
| 🆘 | Emergency, support needed | Technical issues, delays |
| 🎉 | Celebration, completion | Payment confirmed |
| 👏 | Congratulations | Successful sale |
| 🥳 | Happy celebration | Successful purchase |
| ℹ️ | Information | General info |
| 🧪 | Test mode | Sandbox/test transactions |
| 🇨🇩 | Congo pride | Celebration messages |
| ❓ | Question, unclear | AI didn't understand |
| 🇫🇷 | French language | Language requirement |

### Text Formatting
- **Bold** for amounts, actions, status
- UPPERCASE for emphasis (UNIQUEMENT, JAMAIS)
- Numbers for sequential steps (1️⃣ 2️⃣ 3️⃣)
- Line breaks for breathing room

### Message Structure
```
[Emoji] *[Status/Title]*

[Main message - 1-2 lines max]
[Action or next step]
```
